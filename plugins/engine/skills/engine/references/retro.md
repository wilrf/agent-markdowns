# Retro — feed lessons back before you declare DONE

1. **Near-miss pass.** Find what exactly *one* station caught, by design or by luck.
   Strengthen those single-sensor catches.
2. **Promote traps.** Promote any trap that bit twice, cost a phase, or would bite a fresh
   session into the project's loop/lessons doc (or `CLAUDE.md` if it has none). Ship it in
   the final commit. Session-specific noise dies with the task.
3. **Cross-repo bar.** Promotion to a cross-repo home needs the stronger bar: independent
   convergence in a second repo with a different stack.
4. **Prune the harness.** Panels, stations, and subagents correct for today's model, and models
   outgrow them (Claude Code's own team deletes large parts of its prompt and tooling with each
   model release, and treats subagents as "scaffolding for models of today"). Remove a scaffold
   when it no longer changes the outcome. Do not get attached to a verify panel or a fan-out
   the current model no longer needs.
